# GetBoxLanding

Лендинг GetBox: [getbox.ne-nas.ru](https://getbox.ne-nas.ru/)  
Репо: [IncludeSpecial/GetBoxLanding](https://github.com/IncludeSpecial/GetBoxLanding)  
Приложение: [IncludeSpecial/GetBox](https://github.com/IncludeSpecial/GetBox)

## Запуск

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Релизы

Список и скачивание — с GitHub Releases API.  
Создал Release с `*-portable.exe` → на сайте сам появится.

CTA качает актуальную версию напрямую с GitHub.  
Старые версии — в свёрнутом блоке «Предыдущие версии».

## Vercel

Import GetBoxLanding → `npm run build` → `dist` → getbox.ne-nas.ru.
